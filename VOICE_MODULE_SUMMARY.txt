🎓 HOW IT WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Client sends voice (audio data as base64)
   ↓
2. VoiceAgent receives request
   ├─ Validates audio size/duration
   └─ Decodes from base64
   ↓
3. Speech-to-Text (STT)
   ├─ Gets STT provider (Whisper by default)
   └─ Transcribes audio to text
   ↓
4. Language Model (LLM)
   ├─ Sends transcribed text to ChatAgent
   ├─ Retrieves knowledge base (RAG)
   └─ Generates response
   ↓
5. Text-to-Speech (TTS)
   ├─ Gets TTS provider (pyttsx3 by default)
   └─ Synthesizes response to audio
   ↓
6. Return Response
   ├─ Audio as base64
   ├─ Metadata (confidence, duration)
   └─ Optional debug fields
